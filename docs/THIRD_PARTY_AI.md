# Componentes de IA local

## Runtime

O Lírico AI Suite foi preparado para usar o llama.cpp como runtime local.
A distribuição final deve conservar os avisos de licença exigidos pelo projeto.

## Modelo padrão inicial

- Família: Qwen3
- Variante: 8B
- Quantização: Q4_K_M
- Formato: GGUF
- Repositório de origem: Qwen/Qwen3-8B-GGUF
- Licença declarada pelo repositório do modelo: Apache-2.0

O modelo é tratado como componente substituível. O nome exibido ao usuário
é "Lírico AI Standard 8B"; isso não altera a autoria nem a licença dos pesos.
